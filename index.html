售后岗 KPI — 数据参考

KPI 指标定义 衡量标准 权重
响应效率1 首响得分 = X*60% + Y*40%
• X = 个人季度内日平均首响90s
• Y = 首响超过90s的天数 		• X = 个人季度内日平均首响：X ≤ 90s, X=10分; 91s ≤ X ≤ 120s, X=8分; 121s ≤ X, X=4分。
• Y = 首响超过120s的天数：Y=0天，得分10分; 1 ≤ Y ≤ 6天，得分8分; 7 ≤ Y，得分4分。 		10%
响应效率2 响应过程得分 = X*70% + Y*30%

• X = 季度内七鱼日均在线时长 / 季度在线总时长 / 出勤天数

• Y = 季度内远程协助次数（给客户通过线上会议、语音等形式协助客户处理问题） 		• X = 季度内七鱼日均在线时长：X ≥ 8h, 得分10分; 7.3h ≤ X ≤ 7.9h, 得分8分; 6.9h ≤ X ≤ 7.2h, 得分6分; X ≤ 6.8h, 得分4分。
• Y = 远程协助次数：Y ≥ 36次, 得分10分; 20 ≤ Y ≤ 35次, 得分8分; 10 ≤ Y ≤ 19次, 得分5分; 4 ≤ Y ≤ 9次, 得分3分; Y ≤ 3次, 得分0分。
• 出现付费排队超5分钟超过5个，总分减20%（排除集体性问题出现，导致大量消息涌入产生的排队） 		25%
回复质量 有效的快速解决客户问题 • 本项满分10分
① 能理解客户的诉求，并准确回复
② 禁止扯皮，一个问题沟通1个小时以上仍然未给出解决方案
③ 不看聊天记录让客户重复描述问题
④ 反馈的问题，当日闭环，有解决方案就反馈给客户，没有解决方案下班前同步客户处理进度
• 以上问题，每出现一次，扣1分 		25%
学习提效 学习提效分 = X*50% + Q*40% + Y*10%
• X = 所有考核成绩平均分
• Y = 帮助文档维护
• Q = QA每周反馈 		• X = 所有考核成绩平均分：所有考核成绩平均分 ≤ 96, X=10分; 88 ≤ 所有考核成绩平均分 ≤ 95, X=8分; 80 ≤ 所有考核成绩平均分 ≤ 87, X=7分; 79 ≤ 所有考核成绩平均分, X=5分。
• Y = 帮助文档维护：抽查内容没有错误，不被客户投诉帮助文档有问题（0问题，得分10分; 1-2个问题，得分6分; 3个问题及以上，得分0分）。
• Q = QA每周反馈（针对客户常见咨询，整理QA，有清晰的问题描述、解决步骤，不能有错别字，每周按时按量提供）：符合要求按时按量提交，Q=10分; 按时但出现2次内不符合质量的情况，Q=8分; 符合质量但是出现1次不按时提交，Q=8分; 超过3次及以上不符合质量，2次及以上不按时提交，Q=5分; 超过4次及以上不符合质量，3次及以上不按时提交 Q=0分。 		30%
